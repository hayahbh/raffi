# رفّي — النسخة المستقلة

تطبيق رفّي لتتبع القراءة، يشتغل لحاله على الإنترنت بدون Claude.

## وين كل شي؟

| الملف | وش فيه |
|---|---|
| `index.html` | التطبيق كله: الشكل والكود |
| `manifest.json` + `icon.png` | عشان ينضاف للشاشة الرئيسية كتطبيق |
| `supabase/01_schema.sql` | الجداول في قاعدة البيانات |
| `supabase/02_extra.sql` | إضافة: مكان لأي معلومة زيادة |
| `src/cloud.js` | الحفظ والتحميل من Supabase + شاشة الدخول |
| `src/books.js` | البحث في Google Books والتعرّف من الصورة (باركود أو غلاف) |
| `tools/build.py` | يبني `index.html` من رفّي الأصلية + ملفات `src` |
| `test/` | اختبارات بقاعدة بيانات وهمية |

## كيف يشتغل؟

- **الموقع:** GitHub Pages ينشر `index.html`.
- **البيانات:** Supabase. كل مستخدم يشوف بياناته هو بس (Row Level Security).
- **الأغلفة:** في تخزين Supabase داخل `covers/<رقم المستخدم>/`.
- **المفتاح اللي في الكود** (`sb_publishable_…`) عام ومسموح ينكتب، والحماية من القاعدة نفسها.
  المفتاح السري (`service_role` / `secret`) ما ينحط هنا أبدًا.

## التعديل

عدّلي في `src/` ثم ابني:

```
python3 tools/build.py <ملف رفّي الأصلية> index.html
```
